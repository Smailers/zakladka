# Закладка

**Отметка «где я остановился» в любом окне Windows.** Выделите фразу и нажмите **Ctrl+Alt+Z** — на ней появится подсветка. Она держится за сам текст: едет вместе с ним при прокрутке, прячется, когда вы уходите в другой чат или окно, и возвращается, когда этот текст снова на экране. Закладки сохраняются и после перезагрузки компьютера.

> **Пример.** Вы читаете длинный ответ в Claude или ChatGPT, и вас отвлекли. Выделите последнюю прочитанную фразу и нажмите Ctrl+Alt+Z. Завтра откройте этот чат: фраза подсвечена. Если она далеко вверху, у края окна будет плашка **▲ Закладка** — щёлкните по ней, и чат прокрутится к нужному месту.

Windows 10 (версия 1903 и новее) и Windows 11 · один файл `Zakladka.exe` (1,3 МБ) · ничего не нужно устанавливать · всё хранится только на вашем компьютере · лицензия MIT.

## Установка

1. Откройте страницу [Releases](../../releases/latest) и скачайте архив `Zakladka-<версия>-win-x64.zip`.
2. Распакуйте его в постоянную папку, например `C:\Программы\Закладка` (правый щелчок по архиву → «Извлечь все…»). Запускать программу прямо из архива не нужно: Windows распакует её во временную папку, и автозапуск потом не найдёт файл.
3. Дважды щёлкните `Zakladka.exe`. В трее (у часов) появится значок «Закладка», а рядом — подсказка «Закладка: выделите текст и нажмите Ctrl+Alt+Z».

Установщика нет, системные файлы не меняются, в реестр программа ничего не записывает. Нужны только библиотеки, которые есть в любой Windows 10/11.

Если значка не видно, он мог спрятаться под стрелкой **˄** на панели задач. Его можно перетащить оттуда на панель задач.

### Предупреждение SmartScreen

Файл не подписан цифровой подписью, поэтому при первом запуске Windows может показать окно «Windows защитил ваш компьютер» с пометкой «Неизвестный издатель». Чтобы запустить программу, нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Окно появляется только один раз.

Если сомневаетесь, что файл тот самый, сверьте контрольную сумму (см. ниже) или соберите программу из исходников сами ([Для разработчиков](#для-разработчиков)).

### Контрольная сумма SHA256 (необязательно)

Рядом с архивом на странице выпуска лежит `SHA256SUMS.txt`. В нём строки для архива и для `Zakladka.exe`. Проверка в PowerShell:

```powershell
Get-FileHash .\Zakladka-2.0.0-win-x64.zip -Algorithm SHA256
```

Значение в столбце `Hash` должно совпасть со строкой из `SHA256SUMS.txt` (регистр букв не важен). То же самое можно сделать для распакованного `Zakladka.exe`.

### Автозапуск

Чтобы «Закладка» запускалась сама при входе в Windows, выберите любой из двух способов.

**Вручную, без скриптов.** Нажмите Win+R, введите `shell:startup` и нажмите Enter. Откроется папка «Автозагрузка». Перетащите в неё `Zakladka.exe` **правой** кнопкой мыши и выберите «Создать ярлыки».

**Скриптом.** В папке программы щёлкните правой кнопкой `install_autostart.ps1` → «Выполнить с помощью PowerShell» (в Windows 11 этот пункт может быть в «Показать дополнительные параметры»). Окно PowerShell сразу закроется; ярлык можно увидеть в папке `shell:startup`. Чтобы прочитать, что сделал скрипт, выполните его в PowerShell из этой папки:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_autostart.ps1
```

Скрипт создаёт в «Автозагрузке» ярлык «Text Bookmark» на `Zakladka.exe` из своей папки (в папке исходников, где рядом exe нет, — на `target\release\Zakladka.exe`) и ярлык «Закладка» в меню «Пуск» — чтобы снова запустить программу после «Выход». Саму программу он не запускает: она запустится при следующем входе в Windows. Если вы перенесли папку программы, запустите скрипт ещё раз: ярлык переведётся на новое место. Убрать автозапуск — `uninstall_autostart.ps1` тем же способом. Он удаляет оба ярлыка, только если они указывают на `Zakladka.exe` (из любой папки); ярлык прежней версии на Python и ярлык другой программы он не трогает и сообщает об этом.

Ярлык называется так же, как у прежней версии «Закладки» на Python («Text Bookmark.lnk»). Поэтому при переходе скрипт заменяет старый ярлык, и в автозапуске не остаётся двух. Прежнюю версию перед первым запуском новой закройте («Выход» в её панели): вместе они не запускаются. Ярлык неизвестной программы с тем же именем скрипт не трогает: он сообщит об этом и ничего не изменит.

## Как пользоваться

| Что сделать | Как |
|---|---|
| Поставить закладку | выделите текст и нажмите **Ctrl+Alt+Z** |
| Перенести закладку дальше | в том же чате или документе выделите новое место и нажмите **Ctrl+Alt+Z**: старая закладка переедет сюда |
| Добавить ещё одну, не трогая прежнюю | выделите текст и нажмите **Ctrl+Alt+Shift+Z** |
| Перейти к закладке этого окна | нажмите **Ctrl+Alt+Z** без выделения; ещё раз — к следующей |
| Перейти к закладке в другом окне или вкладке | щёлкните значок в трее и выберите закладку в списке |
| Снять закладку | щёлкните красный **✕** у закладки, или выделите отмеченный текст и снова нажмите **Ctrl+Alt+Z**, или нажмите ✕ в списке на панели |

Как выглядит закладка: полупрозрачная **жёлтая подсветка** на словах, **оранжевая полоска** слева и маленький **красный ✕** над полоской. Если закладка сейчас выше или ниже видимой части окна, у края появляется плашка **▲ Закладка** или **▼ Закладка**. Щёлкните по ней, и окно прокрутится к закладке.

У курсора ненадолго появляются короткие сообщения: «Поставлена», «Перенесена», «Снята». Их можно выключить в панели («Подсказки: выкл»). Сообщения об ошибках показываются всегда.

**Основная и дополнительные закладки.** Ctrl+Alt+Z ставит основную закладку («место, где вы остановились»). В одном чате или документе она одна, и новое нажатие переносит её. Ctrl+Alt+Shift+Z ставит дополнительные закладки: их может быть сколько угодно, и они друг друга не заменяют.

**Сколько хранятся.** Закладки старше 30 дней удаляются сами. Если закладок больше 300, остаются 300 самых новых. Оба числа можно изменить в [настройках](#настройки-configjson).

**Сменить сочетания клавиш:** значок в трее → «Клавиши» → щёлкните в поле и нажмите новое сочетание → «Сохранить». Нужны хотя бы два модификатора, и один из них должен быть Alt или Win (например, Ctrl+Alt+Z или Win+Shift+B). Так программа не перехватит обычные Ctrl+C или Ctrl+Z. Если сочетание уже занято другой программой, «Закладка» сразу об этом скажет.

## Панель в трее

Щелчок по значку «Закладка» (левой или правой кнопкой) открывает панель. Повторный щелчок, щелчок мимо панели или Esc её закрывают. Пока панель открыта, отметки на экране спрятаны.

- **Список закладок**: программа, в которой стоит закладка, и начало отмеченного текста. На экране помещается 10 строк, остальные видны при прокрутке колёсиком.
- **Переход**: щелчок по строке. Программа поднимет нужное окно, откроет вкладку браузера или чат, прокрутит к тексту, и закладка мигнёт.
- **«закрыто»**: серая строка значит, что окно или вкладка с этой закладкой сейчас закрыты. Откройте их снова, и закладка вернётся сама.
- **✕ в строке**: удалить эту закладку.
- **«Вернуть: «…»»**: отменить последнее удаление. Программа помнит до 20 удалений, пока она работает.
- **«Удалить все…»**: удалить все закладки. Чтобы это не случилось нечаянно, нужен второй щелчок в течение 4 секунд («Точно удалить все?»). Их тоже можно вернуть.
- **«Метки: показаны / скрыты»**: временно спрятать все отметки на экране. Закладки при этом сохраняются. Отметки снова появятся после повторного щелчка или после перезапуска программы.
- **«Подсказки: вкл / выкл»**: короткие сообщения у курсора («Поставлена», «Снята»…).
- **«Клавиши: … ›»**: сменить сочетания клавиш.
- **«Цвет ›»**: открыть окно цветов.
- **«Справка»**: краткая памятка.
- **«Выход»**: закрыть программу. Закладки сохранятся.

Панелью можно управлять с клавиатуры: ↑ ↓, PageUp, PageDown, Enter (перейти), Delete (удалить), Esc (закрыть). Светлая или тёмная тема панели берётся из настроек Windows.

## Цвета и пипетка

«Цвет ›» в панели открывает окно «Закладка — цвет»:

- **Заливка**: цвет подсветки отмеченного текста. Восемь готовых цветов, «Другой…» (стандартное окно выбора цвета Windows) и «Пипетка».
- **Плотность**: насколько заметна подсветка, от 20 % (едва заметно) до 60 % (ярко). Ползунок можно двигать стрелками ← →.
- **Акцент**: цвет полоски слева, плашек «▲/▼ Закладка» и значка в трее. Выбор такой же, как у заливки.
- **Цвет надписи на плашке**: «Авто» (чёрный или белый — что лучше читается на акценте), «Чёрный», «Белый» или «Другой…». Под кнопками показан контраст, например «Контраст 4,5:1 · Хорошо читается».
- **Как будет выглядеть**: образец с выбранными цветами.
- **«По умолчанию»** возвращает жёлтую заливку 30 %, оранжевый акцент и автоматический цвет надписи. **«Сохранить»** (или Enter) применяет цвета сразу, **«Отмена»** (или Esc) закрывает окно без изменений.

**Пипетка** берёт цвет прямо с экрана. Нажмите «Пипетка», наведите курсор на нужную точку (рядом показывается увеличенный участок 9×9 точек и код цвета) и щёлкните. Esc или правая кнопка мыши отменяют выбор. Пипетка работает на всех мониторах.

## Где работает

**Чаты и браузеры** — через специальные возможности Windows (UI Automation):

- Claude, ChatGPT, Codex, Antigravity и другие программы на Electron;
- браузеры на Chromium: Brave, Chrome, Edge;
- Блокнот и другие программы, которые отдают выделенный текст через специальные возможности Windows.

Здесь подсветка ложится точно на выделенные слова, едет за текстом при прокрутке и работают плашки ▲/▼. Из панели можно перейти к закладке: в браузере откроется нужная вкладка, в чат-программе — нужный чат.

**Программы, которые рисуют текст картинкой** (например, ONLYOFFICE) — через распознавание текста на экране (Windows OCR). Выделенный текст копируется (Ctrl+C), и программа находит эти слова на снимке окна. Распознавание работает для русского и английского языков, а если они не установлены — для языка Windows. Закладка ставится примерно за 0,4 секунды.

Отметки рисуются только у окна на переднем плане и только там, где текст сейчас виден: не поверх другого окна и не на месте, откуда текст уже уехал.

## Известные ограничения

- **Закладки по распознаванию** (ONLYOFFICE и подобные): во время прокрутки отметка прячется и появляется снова, когда картинка успокоится. Плашек ▲/▼ и прокрутки к такой закладке нет: она подсветится, когда этот текст окажется на экране.
- **Длинные чаты**, которые выгружают далёкие сообщения из памяти, не сообщают о тексте, пока до него не долистать. Плашка ▲/▼ там может не появиться, а переход из панели может ответить «Текст закладки на странице не найден». Долистайте ближе к закладке, и она появится.
- **Где Ctrl+C не нажимается никогда:** терминалы и консоли, программы удалённого доступа (AnyDesk, TeamViewer, RDP и другие), виртуальные машины, редакторы кода и IDE, браузеры и Electron-программы, окна Java-программ и Python, Excel и окна таблиц (`.xlsx`, `.csv` и т. п. в заголовке). Ctrl+C там может прервать работающую программу. Если такая программа сама не отдаёт выделенный текст, поставить закладку в ней нельзя: программа скажет «Это окно не отдаёт выделенный текст».
- **Окна, запущенные от имени администратора**, обычной программе Windows недоступны.
- **Первый раз в окне на Chromium** программа может подождать около секунды, пока окно подготовит текст для специальных возможностей.
- **Отставание при прокрутке.** Метка обновляется до 60 раз в секунду. Отставание 0,1–0,2 секунды задаёт сам Chromium: он сообщает новое положение текста с такой задержкой.
- Одновременно может работать только одна «Закладка». Второй запуск тихо завершается. Вместе с прежней версией на Python она тоже не запускается.

## Как это работает

**Якорь по тексту, а не по координатам.** При постановке закладки программа запоминает:

- цитату (выделенный текст);
- 64 символа до неё и 64 символа после;
- адрес страницы, а если адреса нет — заголовок;
- название вкладки или чата и имя программы.

Текст сравнивается в «плоском» виде: без учёта регистра, ё = е, без пробелов, переносов строк и невидимых символов. Поэтому другая ширина окна, масштаб или перенос строк не мешают найти то же место. Если цитата встречается на странице несколько раз, выбирается вхождение с совпадающим контекстом. Если текст немного изменился, используется нечёткое сравнение.

**UI Automation** — интерфейс специальных возможностей Windows, тот же, через который работают экранные дикторы. Через него программа спрашивает у окна, какой текст выделен и где на экране нужные слова. Положение метки обновляется до 60 раз в секунду, пока текст движется, и реже, когда всё спокойно.

**Распознавание текста (OCR)** — для программ, которые рисуют текст картинкой и не отдают его через UI Automation. Используется встроенный в Windows движок `Windows.Media.Ocr`. Он создаётся только когда нужен и освобождается через минуту простоя.

**Ctrl+C только там, где это безопасно.** Программа нажимает Ctrl+C, только если выделенный текст нельзя получить иначе, распознавание доступно и окно не из списка исключений ([см. ограничения](#известные-ограничения)). Перед этим она ждёт, пока вы отпустите клавиши-модификаторы. Всё содержимое буфера обмена (текст, картинки, другие форматы) сохраняется и сразу после копирования возвращается на место. Если в буфере больше 64 МБ, программа его не трогает и Ctrl+C не нажимает.

### Сколько ресурсов занимает

| | |
|---|---|
| Память | 2,7–6,6 МБ (прежней версии на Python требовалось около 55 МБ) |
| Процессор, когда на экране есть метка | около 0,5 % одного ядра |
| Постановка закладки по распознаванию | около 0,4 секунды |
| Размер | один файл `Zakladka.exe`, 1,3 МБ |

## Приватность

- **Всё остаётся на компьютере.** Программа не обращается к сети: в ней нет сетевого кода, телеметрии и проверки обновлений.
- **Что хранится в закладках.** `bookmarks.json` хранит цитату, по 64 символа до и после неё, начало текста для списка, заголовок окна, название вкладки или чата и адрес страницы. Файл хранится открытым текстом в вашей папке данных (см. ниже) и больше никуда не попадает.
- **В журналах нет текста.** В журналы пишутся только коды событий, время, числа, координаты прямоугольников и первые 8 символов номера закладки. Текст ошибки (паники) не пишется никогда, потому что он может содержать ваш текст, — только место в коде.
- **Буфер обмена** возвращается в прежнее состояние после Ctrl+C. Восстановленное содержимое помечается так, чтобы не попасть в журнал буфера обмена Windows (Win+V) ещё раз. Сам скопированный фрагмент кладёт в буфер другая программа. Поэтому, если журнал буфера обмена у вас включён, этот фрагмент может оказаться в журнале, как при обычном Ctrl+C. Если это нежелательно, поставьте `"copy_fallback": false` (см. [настройки](#настройки-configjson)).

### Где лежат данные

Папка `%LOCALAPPDATA%\text-bookmark\` (вставьте этот путь в адресную строку Проводника):

| Файл | Что в нём |
|---|---|
| `bookmarks.json` | закладки |
| `config.json` | настройки (создаётся при первом запуске) |
| `error.log` | коды ошибок и время, без текста |
| `bookmarks.json.bad` | появляется, только если `bookmarks.json` оказался повреждён: программа откладывает его в сторону и начинает с пустого списка |
| `timing.log`, `debug-state.json`, `debug-render.log` | только при `"debug": true`: время операций в миллисекундах и координаты, без текста |

Размер каждого журнала ограничен 1 МБ: после этого новые строки не пишутся.

## Если в Windows нет распознавания текста

В урезанных сборках Windows может не быть распознавания текста (OCR) или ни одного языка для него. Тогда при каждом запуске «Закладка» покажет сообщение об этом и продолжит работать: в чатах, браузерах и Блокноте всё работает как обычно. Не будут ставиться только закладки в программах, которые рисуют текст картинкой (например, в ONLYOFFICE).

Как добавить распознавание:

- **Параметры → Время и язык → Язык** → выберите язык (например, русский) → «Параметры языка» → в разделе дополнительных компонентов установите «Распознавание текста» (OCR);
- или в PowerShell **от имени администратора**:

  ```powershell
  Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"
  ```

  Для английского — `Language.OCR~~~en-US~0.0.1.0`.

После установки перезапустите «Закладку». Если распознавание вам не нужно и сообщение мешает, поставьте `"ocr": false` в `config.json`.

## Для разработчиков

### Требования

- Windows 10/11 x64.
- Rust stable с набором **`x86_64-pc-windows-gnu`**. Его компоновщик (`rust-mingw`) входит в сам набор, поэтому Visual Studio и Windows SDK не нужны. Собиралось на Rust 1.99.1.

```powershell
winget install --id Rustlang.Rustup -e
rustup toolchain install stable-x86_64-pc-windows-gnu
rustup default stable-x86_64-pc-windows-gnu
```

Зависимости: `windows` (Win32, COM UI Automation, WinRT OCR), `unicode-normalization` (NFKC), `caseless` (полный casefold), `serde_json` с `preserve_order`. Интерфейс написан на голом Win32 + GDI, без GUI-фреймворков и асинхронных сред.

**Почему `windows = "=0.58.0"` закреплён.** Версии 0.61 и новее требуют `dlltool` с ассемблером, которого нет в наборе `rust-mingw`: 0.62.2 этим набором не собирается, 0.58.0 собирается. Не поднимайте версию без проверки сборки на `x86_64-pc-windows-gnu`. `Cargo.lock` лежит в репозитории.

### Сборка

`build.ps1` сам добавляет `%USERPROFILE%\.cargo\bin` в `PATH` процесса, вызывает `cargo` и возвращает его код выхода:

| Команда | Что делает |
|---|---|
| `.\build.ps1` или `.\build.ps1 check` | `cargo check --all-targets` |
| `.\build.ps1 test` | `cargo test` |
| `.\build.ps1 build` | `cargo build` → `target\debug\Zakladka.exe` |
| `.\build.ps1 release` | `cargo build --release` → `target\release\Zakladka.exe` |

Остальные аргументы передаются `cargo` как есть: `.\build.ps1 test --test core`. Если задан `CARGO_TARGET_DIR`, сборка идёт туда, а не в `target\`. Если политика выполнения не разрешает скрипты, запускайте так: `powershell -ExecutionPolicy Bypass -File .\build.ps1 release`.

Профиль `release`: `opt-level = 3`, `lto = "fat"`, `codegen-units = 1`, `strip = true`, `panic = "unwind"`. Паника в одном тике не роняет программу: каждый цикл и каждая оконная процедура обёрнуты в `catch_unwind`, а в `error.log` попадает только файл и строка паники.

Манифеста и ресурсов в exe нет. Поддержка DPI (per-monitor v2) включается вызовом до первого окна. У файла в Проводнике стандартный значок; значок в трее программа рисует сама.

### Профиль разработки `--dev`

`Zakladka.exe --dev` запускает отдельную копию, которая не мешает рабочей:

| | обычный запуск | `--dev` |
|---|---|---|
| Папка данных | `%LOCALAPPDATA%\text-bookmark\` | `%LOCALAPPDATA%\text-bookmark-native\` |
| Клавиши по умолчанию | Ctrl+Alt+Z, Ctrl+Alt+Shift+Z | Ctrl+Alt+X, Ctrl+Alt+Shift+X |
| Мьютекс | `Local\TextBookmark.v1` | `Local\TextBookmark.native.dev` |
| Акцент и значок в трее | оранжевый `#FF7A00` | зелёный `#34C759` |
| Подсказка значка | «Закладка — Ctrl+Alt+Z» | «Закладка (новая) — Ctrl+Alt+X» |

Не ставьте закладку обеими копиями на один и тот же текст: ✕ и плашка одной копии для другой выглядят как чужое окно поверх текста.

Помощники в `dev\` рассчитаны на `--dev`-копию: `stats.ps1` и `windows.ps1` берут её PID из `dev.pid` (его записывает `run-dev.ps1` в папку данных `--dev`), а `post-tray.ps1` и `panel-check.ps1` ищут первое окно класса `ZakladkaOwner` и при запущенной рабочей копии могут попасть в неё:

| Скрипт | Что делает |
|---|---|
| `run-dev.ps1 [-DebugBuild]` | (пере)запускает `--dev`-копию из `target\release` (или `target\debug`). При первом запуске создаёт `config.json` с `"debug": true`. Останавливает только прежний процесс, чей PID записан в `dev.pid` и чей путь лежит в этой папке |
| `stats.ps1` | память и процессор `--dev`-копии, дописывает строку в `stats.log` |
| `windows.ps1` | видимые окна `--dev`-копии: класс, прямоугольник, длина заголовка |
| `post-tray.ps1` | имитирует щелчок по значку в трее |
| `panel-check.ps1` | открывает и закрывает панель, между шагами перечисляет окна |
| `clip-hash.ps1` | «отпечаток» буфера обмена (число форматов, длина текста, начало SHA-256), без самого содержимого |

### Самопроверка `--selftest`

Самопроверка ищет текст в окне программы через UI Automation и печатает JSON с координатами. Она ничего не нажимает, не сохраняет и не меняет фокус. Мьютекс не берёт, поэтому работает рядом с запущенной копией. У exe нет консоли, поэтому результат пишется в файл `--out`:

```powershell
.\Zakladka.exe --selftest find "фраза из чата" claude.exe --out "$env:TEMP\selftest.json"
```

| Режим | Что делает |
|---|---|
| `find "<фраза>" [exe]` | находит фразу в окне: число вхождений, строки, видимая часть, направление ▲/▼, проверка «текст не перекрыт» |
| `auto [exe]` | то же для фразы, которую самопроверка берёт из середины окна сама |
| `selection [exe]` | что сейчас выделено: первые 120 символов и прямоугольники |

По умолчанию `exe` — `claude.exe`. Если окна этой программы нет, код выхода 2 и `{"error": "no window of …"}`.

### Устройство

Три потока:

- **UI** (главный) — цикл сообщений, скрытое окно-владелец, значок в трее, `RegisterHotKey`, заранее созданные окна меток (24 подсветки, 6 полосок, 6 флажков ✕, 2 плашки), подсказки, панель, окно цветов и окно клавиш. UI Automation этот поток не вызывает никогда. В покое он спит в `GetMessageW`.
- **tracker** (MTA) — владеет списком закладок и состоянием слежения. Тик 16 мс, пока текст движется, реже, когда всё спокойно. Двигает окна меток через `SetWindowPos(… SWP_ASYNCWINDOWPOS)`, отвечает за OCR.
- **locator** (MTA) — медленная работа: сканирование документа, статусы «закрыто», переход к закладке.

Потоки связаны каналами `mpsc`. Чтобы разбудить tracker, используется событие `Wake`, чтобы разбудить UI — `PostMessageW`. Договор «что `Send`/`Sync`» проверяет компилятор: блок `const _` в `src\lib.rs`.

```
src\
  main.rs        вход: аргументы, мьютекс профиля, DPI, папка данных, запуск UI
  lib.rs         модули программы (их видят тесты tests\*.rs)
  app_id.rs      профили: обычный и --dev
  types.rs       общие типы и сообщения между потоками
  core\          чистая логика без Win32
    flatten.rs     «плоский» текст: NFKC, casefold, ё→е, без пробелов и невидимых символов
    matching.rs    поиск цитаты и контекста, нечёткое сравнение
    geometry.rs    прямоугольники, строки, направление ▲/▼
    rules.rs       где можно Ctrl+C, заголовки и адреса страниц, выбор вхождения, перенос позиции
    hotkey.rs      разбор сочетаний клавиш
    color.rs       цвета, контраст WCAG
    text.rs        тексты интерфейса и справки
  store\         config.json, bookmarks.json, журналы, местное время, id
  win\           Win32: окна и процессы, снимок экрана, буфер обмена и Ctrl+C, значок, точное ожидание
  uia.rs         UI Automation
  ocr.rs         Windows OCR
  tracker\       поток слежения: цикл и слежение (mod, follow), окна меток (overlay),
                 постановка и переход (mark), поток locator (locator), состояние (state)
  selftest.rs    --selftest
  ui\            окно-владелец (host), трей, клавиши и их окно, окна меток (pieces), сообщения (toast),
                 пояснения (tooltip), рисование (gfx), панель (panel, panel_model),
                 окно цветов (color_dialog, color_model), пипетка (eyedropper)
build.rs         вшивает в exe значок (лента-закладка из src\core\ribbon.rs) и сведения о файле
tests\           интеграционные тесты; golden\ — эталонные данные
tools\gen_golden.py   генератор эталонов из прежней версии на Python
dev\             помощники для --dev-копии
build.ps1  dist.ps1  install_autostart.ps1  uninstall_autostart.ps1
```

**Совместимость с прежней версией на Python.** Формат `bookmarks.json` (`{"version": 1, "bookmarks": [...]}`) не изменился: обе версии читают файлы друг друга, и файл записывается байт в байт так же. Ключи и проверки `config.json` те же. Разница одна: прежняя версия хранила `config.json` рядом со скриптом, а эта хранит его в папке данных. Сам он не переносится: если вы меняли настройки в прежней версии, скопируйте её `config.json` в `%LOCALAPPDATA%\text-bookmark\` до первого запуска новой. В обычном режиме у обеих версий одна папка данных и один мьютекс, поэтому одновременно они не запускаются. Вернуться назад просто: выйти из новой версии и запустить старую.

### Тесты

Всего 181 автотест (в `tests\*.rs` и внутри модулей). Часть тестов создаёт скрытые окна и обращается к GDI и UI Automation, поэтому запускайте их в обычном сеансе Windows с рабочим столом.

### Выпуск

1. Поднимите `version` в разделе `[package]` файла `Cargo.toml`.
2. Запустите:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\dist.ps1
   ```

   Скрипт:
   - берёт версию из `version` раздела `[package]` в `Cargo.toml`;
   - выполняет `build.ps1 release` и останавливается, если сборка не удалась. Exe берётся из `target\release\` (или из `CARGO_TARGET_DIR`, если он задан). Если из этой папки запущена `--dev`-копия (`run-dev.ps1`), закройте её: занятый exe `cargo` не перезапишет;
   - читает таблицу импорта `Zakladka.exe` (обычную и отложенную) и проверяет, что это x64. Допустимы только системные библиотеки, которые есть в любой Windows 10/11: `kernel32`, `user32`, `gdi32`, `advapi32`, `ole32`, `oleaut32`, `combase`, `uiautomationcore`, `ntdll`, `msvcrt`, `bcrypt`, `bcryptprimitives`, `shell32`, `comdlg32`, `dwmapi`, `shcore`, `api-ms-win-*`. Любая другая библиотека (например, `libgcc_s_seh-1.dll` или `libwinpthread-1.dll`) останавливает выпуск: её нужно вшить статически, а не класть рядом;
   - кладёт `Zakladka.exe`, `README.md`, `LICENSE`, `install_autostart.ps1`, `uninstall_autostart.ps1` в папку `dist\Zakladka-<версия>-win-x64\` и упаковывает их (без вложенной папки) в `dist\Zakladka-<версия>-win-x64.zip`, затем проверяет состав архива;
   - записывает рядом `dist\SHA256SUMS.txt` с суммами архива и `Zakladka.exe` (строки `<sha256>  <имя файла>`, как у `sha256sum`).

   Повторный запуск пересоздаёт эту папку, архив и `SHA256SUMS.txt`; другие файлы в `dist\` (например, архивы прежних версий) не трогаются.
3. Желательно проверить запуск на чистой Windows (Windows Sandbox или виртуальная машина).
4. Загрузите оба файла в GitHub Releases, например:

   ```powershell
   gh release create v2.0.0 dist\Zakladka-2.0.0-win-x64.zip dist\SHA256SUMS.txt
   ```

Папки `target*\` и `dist\` в репозиторий не попадают (`.gitignore`).

Официальные выпуски собирает GitHub Actions (`.github\workflows\build.yml`): на каждый push — тесты, сборка, проверка библиотек и архив (неподписанная сборка остаётся во вкладке Actions); на метку `v*` — ещё подпись `Zakladka.exe` через SignPath и черновик выпуска с подписанным архивом и `SHA256SUMS.txt`.
